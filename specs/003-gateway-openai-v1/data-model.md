# Data Model: Gateway and OpenAI-Compatible /v1

## Model resolution

An ephemeral service result, not a table.

| Field | Type | Rule |
|---|---|---|
| requested_id | UUID string | Parsed before database/engine work |
| model_id | UUID | Must equal a registry primary key |
| slug | string | Database-derived; never returned as engine selection input from caller |
| context_window | positive integer | Registry/capability profile value |
| entitlement_verdict | allowed/refused | Refused is externally indistinguishable from missing |
| engine_id | UUID or null | READY/STARTING only; STOPPING is never routable |
| node | declared node name or null | Comes from the engine/copy relationship |
| engine_url | internal URL or null | Constructed from declared control endpoint and recorded port |

Resolution succeeds only when the model exists and is visible to the principal. Non-admin visibility
requires `published` and `ready`; entitlement labels must be empty or covered by principal scopes.

## Usage record

Append-only PostgreSQL entity `usage_records`.

| Field | Type | Rule |
|---|---|---|
| id | UUID | Generated by gateway |
| request_id | UUID | Unique; also emitted as response/request correlation id |
| principal_kind | enum string | anonymous/admin/user/service |
| principal_subject | string or null | No bearer material |
| requested_model_id | string | Caller value after bounded validation; accounting only, never engine-bound |
| model_id | UUID FK or null | Registry model; null when resolution is refused as absent |
| engine_id | UUID FK or null | Null when rejected before engine selection |
| protocol | openai/anthropic | Requested wire dialect |
| prompt_tokens | non-negative integer | Engine count when present, otherwise known lower bound |
| completion_tokens | non-negative integer | Tokens actually observed/reported |
| duration_ms | non-negative float | Accepted request to terminal accounting |
| outcome | succeeded/failed/disconnected/refused | Exactly one terminal value |
| failure_code | short string or null | Stable category, never an engine traceback |
| started_at | timestamptz | Gateway acceptance time |
| finished_at | timestamptz | Finalizer time |

Indexes: unique `request_id`; `(model_id, started_at)`; `(principal_subject, started_at)`; `outcome`.
The migration is additive and reversible by dropping this table and its enum types/indexes.

## Request context

In-memory per-request object containing request UUID, principal, protocol, model resolution,
wait preference/deadline, acquired engine semaphore, trace identity, counters, and terminal outcome.
It owns cleanup: release the slot, close upstream HTTP, and shield usage persistence.

## State transitions

```text
received → refused
received → resolving → cold_wait → proxying → succeeded
                              ↘ load_failed → failed
                    ↘ saturated → refused
proxying → disconnected
proxying → engine_failed → failed
```

No transition from a terminal state is permitted. A usage row is written once for every request
that reaches `resolving`; malformed FastAPI validation failures remain framework-level 422s.
